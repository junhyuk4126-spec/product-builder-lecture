# Lotto Number Generator

## Overview

This is a simple web application that generates random lottery numbers.

## Project Outline

*   **`index.html`**: The main HTML file.
*   **`style.css`**: The CSS file for styling.
*   **`main.js`**: The JavaScript file for the lottery number generation logic.

## Current Plan

    *   Add a button to generate the numbers.
2.  **Modify `style.css`**:

3.  **Modify `main.js`**:
